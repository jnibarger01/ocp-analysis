# OCP Analysis

Modern Hendrick-themed oil-change package break-even calculator.

## Purpose

This tool compares a six-service prepaid oil-change package against regular pay-per-visit pricing.

Default values:

- Package price: `$434.56`
- Pay-per-visit cost: `$150.00`
- Package services: `6`
